# 23 — Lineage and Blend

Gate 1 and Gate 2. Every direction descends from someone. This file makes the descent explicit, so the result is a blend that belongs to the subject and not a copy of any single source.

**The rule:** never copy one source. Blend three, each owning a different axis, and push all three through the subject until no single source can be named.

## 1. Why blend

A single reference produces cosplay: the page reads as "a Müller-Brockmann poster" or "a Godly site with the logo swapped". Two references that agree produce a pastiche of their shared school. Three references with a tension between them, each restricted to one axis, produce something none of them could have made.

Templates count as sources. A project scaffolded from a BUREAU template starts at similarity 1.0 with that template and must move away from it before Gate 2 (§7).

## 3. The blend recipe

Pick exactly three lineages and give each a weight and an axis.

| Role | Weight | Owns | Job |
|---|---:|---|---|
| **Dominant** | 50–60% | one structural axis: grid, composition, or content logic | gives the page its order |
| **Counter** | 25–35% | one expressive axis: voice, light, or depth | pulls against the dominant |
| **Accent** | 10–20% | one behaviour: motion, icons, or scroll narrative | the detail a visitor notices second |

Rules:

1. **One axis per lineage.** Two lineages may not own the same axis. If Tufte owns content logic, Vignelli cannot also own it.
2. **Tension is required.** Dominant and counter must disagree: order × volume, flatness × depth, restraint × noise. If they agree, you have a school, not a blend.
3. **Cross a border.** At most two lineages from the same school (Swiss, Bauhaus, New Wave). The third comes from another discipline: film, data, product, cartography.
4. **Principle, not look.** Write each contribution as one sentence that contains no visual noun from the original work.
5. **Through the subject.** Each principle must be re-expressed in the subject's material. Write what it **becomes**.
6. **One ingredient nobody gave you.** Add one element that comes only from the subject: a material, a time, a place, a dataset. Name it.

## 4. The blend file

Write `.bureau/comps/blend.md` for the chosen direction. Gate 1 requires it.

```markdown
# Blend — <direction name>

| Role | Lineage | Principle (one sentence) | Axis | Becomes, in this subject | Do not copy |
|---|---|---|---|---|---|
| Dominant 55% | Edward Tufte | Every mark carries data; compare by repeating the frame | Content logic | Three waterlines on the same coastal section | His book layouts |
| Counter 30% | Massimo Vignelli | One family, a strict grid, the diagram over the picture | Type, navigation | IBM Plex only; the nav is a transit line | The subway map styling |
| Accent 15% | Otl Aicher | A restricted palette and pictograms on one grid | Colour, icons | Five asset pictograms on a 24-unit grid; no red, no black | The 1972 pictograms |

- Tension: data austerity (Tufte) against diagrammatic boldness (Vignelli).
- Subject-only ingredient: the waterline itself, moved by the visitor.
- Attribution test: <who looked, what they named>
- Divergence: `.bureau/evidence/divergence.json`, highest pair <value>
```

## 5. Mutation checklist

A borrowed principle has been transformed only when every line is true:

- [ ] It changed medium: print or film became something only a browser can do (live time, input, scroll, real-time light).
- [ ] It changed scale or unit: page → viewport, poster → component, frame → state.
- [ ] It changed content: it now carries this subject's facts, not the source's.
- [ ] It lost its signature: the source's most famous visual trait is absent.
- [ ] It gained a constraint: accessibility, performance, or locale forced a decision the source never faced.

## 6. Originality tests

Run all four before Gate 2.

1. **Attribution test.** Show the first viewport to someone who knows design history. If they name one source with confidence, the dominant is above 60% or the "do not copy" line was ignored. Rebalance.
2. **Swap test.** Replace the subject with a competitor's. If the page still works unchanged, the blend never went through the subject (§3 rule 5).
3. **Divergence test.** Run the fingerprint comparison against the scaffold template, the sibling templates, and any reference you saved locally:

   ```bash
   node "$BUREAU_DIR/scripts/divergence.mjs" index.html --templates --out .bureau/evidence/divergence.json
   node "$BUREAU_DIR/scripts/divergence.mjs" index.html .bureau/comps/ref-*.html --max 0.35
   ```

   The script compares palette (perceptual bins), faces, easing curves, CSS declarations, class vocabulary, section skeleton and favicon. Above 0.35 is a copy with new words; the report names the dimensions to change.
4. **Grayscale test.** In a grayscale thumbnail the page must still be recognizable. If only the colour separates it from a source, the blend is a reskin.

Each template folder holds a `LINEAGE.md` with the full recipe and the list of what a project must change.

When you scaffold from a template:

- Keep only what the brief justifies; write the new blend before touching CSS.
- Change at least five of the seven fingerprint dimensions.
- Reach divergence ≤ 0.35 against **every** bundled template before Gate 2. The scaffold's own `LINEAGE.md` is not your lineage.

## 8. Failure modes

| Failure | Symptom | Fix |
|---|---|---|
| **Tribute act** | One lineage above 60%; the attribution test names it | Demote it to counter; promote a lineage from another discipline |
| **School photo** | Three Swiss modernists | Replace the accent with film, data, or product |
| **Axis fight** | Two lineages both set the type | Give one of them a different axis or drop it |
| **Look transfer** | "Bass-style cut-paper hero" | Rewrite as a principle without visual nouns |
| **Name-dropping** | The blend file is filled in, the page is unchanged | Point each row to the selector, component, or file that carries it |
| **Template drift** | Divergence vs scaffold above 0.35 | Change faces, palette, easing, skeleton and favicon first |

## 9. Gate evidence

- Gate 1: `.bureau/comps/blend.md` with three rows, tension, subject-only ingredient.
- Gate 2: `.bureau/evidence/divergence.json` with every pair ≤ 0.35, and the attribution-test note.

Credit the lineages in the case study. Naming the sources is how a blend stays honest.
