Three endpoints. That is the whole API.

      
Every response carries a confidence between 0 and 1 and the reason for it, so your code can decide when to ask the person again.

    

    

      
MethodPathDoes

      
        
GET/v1/search?q=Free text to a ranked list of places, with coordinates and confidence.

        
GET/v1/reverse?lat=&lon=Coordinates to the nearest address a postal service would accept.

        
POST/v1/batchUp to 10,000 lines of a spreadsheet, matched in one request.

      
    

  


  

    

      
The matching is a programme, and you can read it.

      
Three rules, applied in order. The playground above runs the same rules on a ten-city index.

    

    

      
Fold
Lowercase, strip accents and punctuation, so São and sao are the same word.
"São Paulo" → "sao paulo"

      
Compare
Score every candidate by shared letter pairs, so one wrong letter costs little.
dice("paolo", "paulo") = 0.75

      
Explain
Return the score and the rule that decided it. The swatch is the longitude, as a hue.
hue = (lon + 180) / 360 × 360
