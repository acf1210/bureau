What planners ask first.

Is this a flood map?

No. A flood map answers where water goes. The desk answers what stops working first, and in what order, so a plan can be sequenced.

Where does the data come from?

This template ships with an illustrative dataset. A real deployment connects a licensed sea-level model, a tide-gauge feed and the municipality's asset register.

Can it run offline?

Yes. The interface is static and the model compiles to a local file, which matters for councils with restricted networks and for field reviews.
