The average is the enemy.

Models are trained on the internet's mean. Without direction, that mean becomes the design. BUREAU replaces the reflex with a decision.

Slop is not "made by AI". It is the same hero, the same gradient, the same three cards, the same vague promise — reproduced without a point of view.

The fix is not more decoration. It is a specific subject, a real constraint, a named signature, and a review that refuses to average a hard failure away.

Read the anti-slop taxonomy ↗

  • BS-K01Purple-to-blue gradient as the brand→ Anchor the palette in a material, a place, a memory.
  • BS-C01Centered pill + H1 + subtitle + two buttons→ Commit to object, stage, split argument, index or live proof.
  • BS-M01Fade-up on every section→ One entrance sequence, then quiet.
  • BS-W03Unsourced uptime and customer counts.→ Source and date, or remove the claim.
  • BS-I04A fake dashboard with the same bar chart→ Build the real view, or a diagram that explains.
  • BS-T01The default AI font pairing as the entire identity→ Give display type its own voice.

Install once. Use everywhere.

The same skill folder works across four hosts. Preview with a dry run, then restart the agent and call /bureau.

Requires Node 20+. Playwright is optional and degrades to manual screenshots. Figma MCP is optional and degrades to exported variables.

Installation guide ↗

Windows: use install.ps1. Uninstall removes only folders with the BUREAU marker.

git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent claude --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent codex --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent antigravity --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent hermes --scope user

Or install everywhere: bash installers/install.sh --agent all --scope user --dry-run
