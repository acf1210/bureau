Proof

Every page gets a proof.

The detector marks a generic generated page in red pencil, with the same rules the command line runs. Flip to the reviewed version, or proof this page.

Argument

A model draws the average. An editor marks it.

Asked for a page with no direction, a model returns the centre of everything it has seen. That is not a prompt problem; it is a missing idea, a missing point of view and a missing review.

Concept before pixels.Three directions that truly differ, each a blend of three designers on three axes, built from a survey of five verified references. No code before an idea, an emotional target and a world.

Craft with limits you can check.Type, colour, composition and motion each have a reference and a budget; scripts measure what can be measured, from contrast and overflow to fingerprint divergence.

A review that can refuse.Ten gates in order, evidence on every line, a ten-minute jury and a Tribunal in a fresh context. Invented proof, fake sends and hidden content fail whatever the score.

Circuit

Ten gates. One Tribunal.

Each gate scores 0 to 5 against its weight; any gate under 3.5, any P0 or any missing evidence fails the release. Changing a source file makes every later gate stale.

Judge before you measure.The design review is written before anyone reads the detector's output.

The builder is the weakest reviewer.The Tribunal reads the work in a fresh context, or the run is declared degraded and cannot reach Award Track.

Ten minutes for the jury.Ten to fifteen independent reviewers vote on every gate and every Law of UX; the best round inside the time box stands.

Install

One folder, four hosts.

Preview with a dry run, restart the agent, then call /bureau. Node 20 or later; Playwright and Figma are optional and degrade honestly.

The installer copies the skill folder into the host's skills directory and marks it, so uninstalling removes only what it placed.

Windows: installers/install.ps1. Installation guide.

git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent claude --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent codex --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent antigravity --scope user
git clone https://github.com/acf1210/bureau.git cd bureau bash installers/install.sh --agent hermes --scope user

Every host at once: bash installers/install.sh --agent all --scope user --dry-run
